# TI-84 Plus CE Pseudo-3D Racer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Polytrack-style time-trial racer (`RACER.8xp`, ≤75 KB) with 6 tracks, best times and ghost cars, running on a TI-84 Plus CE with OS 5.4.

**Architecture:** Game logic (track, physics, race/ghost, save format) is plain portable C with no CE headers, so it is unit-tested on the host with gcc. Platform code (render, input, main loop) uses graphx/keypadc/fileioc. A host build links the whole game against small shim implementations of those three libraries so a scripted "sim" can drive the real game and dump PNG screenshots — there is no TI ROM here, so CEmu cannot run.

**Tech Stack:** C (CE C toolchain / CEdev at `/opt/CEdev`, ez80-clang), graphx, keypadc, fileioc; host: gcc, make, python3 (PPM→PNG via stdlib `zlib`).

**Spec:** `docs/superpowers/specs/2026-10-20-ti84-racer-design.md`

## Global Constraints

- Program size: `bin/RACER.8xp` ≤ 75 KB (76800 bytes).
- Target: TI-84 Plus CE, OS 5.4; budget for the slowest hardware revision. Target ~30 fps, never below ~20 fps.
- Physics: deterministic fixed-point (`int32_t` only, no floats) at a fixed **30 ticks/s**, decoupled from render rate.
- Saves in archived AppVars; survive a RAM reset.
- No track editor, no multiplayer, no medals.
- Restart is instant: no loading screen, no delay.
- Files under `src/` that are logic (`track.*`, `physics.*`, `race.*`, `savefmt.*`) must not include any CE header.

## Review Focus

1. Corrupt, truncated or old-version save AppVar → treated as "no best yet", never a crash. (Task 4 test `test_load_rejects_corrupt`.)
2. A run that goes past the ghost buffer cap (e.g. player idles at the start) → timer freezes at the cap, the run is not saved, the game doesn't crash. (Task 3 test `test_cap_run`.)
3. Reversing back over a checkpoint or behind the start line → position clamps at 0, each checkpoint counts once and in order. (Task 2 `test_no_reverse_past_start`, Task 3 `test_checkpoint_once`.)
4. Frame drops (slow frame) → race time stays accurate because physics catches up in ticks, capped at 4 ticks per frame so the game doesn't spiral. (Task 6 step "catch-up cap".)
5. Saving a new best when the archive write fails → the old best survives (write to temp AppVar, then delete old + rename). (Task 4 test `test_save_keeps_old_on_failure`.)

- `src/track.h`:
  ```c
  #define SEG_LEN 200            /* world units per segment (fx-free ints) */
  #define MAX_SEGS 1200
  #define MAX_CP 8
  typedef struct { uint8_t count; int8_t curve; int8_t hill; } section_t; /* curve -6..6 (right +), hill = height change per segment */

  ```

### Task 2: Physics

**Files:** Create `src/physics.h`, `src/physics.c`, `tests/test_physics.c`

**Interfaces:**
- Consumes: `track_t`, `fx`, `SEG_LEN`.
- Produces:
  ```c
  enum { IN_GAS = 1, IN_BRAKE = 2, IN_LEFT = 4, IN_RIGHT = 8 };   /* 4 bits, packable */
  typedef struct { int32_t z; fx x; fx speed; int8_t drift; uint8_t wall_hit; } car_t;
  /* z: world units along track (>=0). x: lateral, FX_ONE = road edge. speed: world units/tick in fx. */
  #define MAX_SPEED  FX(60)        /* ≈ top speed; tune in Task 6 */
  #define MAX_REVERSE FX(10)
  void car_reset(car_t *c);
  void car_step(car_t *c, const track_t *t, uint8_t input);
  ```
- Model (values tunable, behavior fixed):
  - Gas accelerates with acceleration falling off toward `MAX_SPEED`. Brake decelerates hard. Gas+brake = brake. Brake held at `speed <= 0` reverses down to `-MAX_REVERSE`. Neither key: gentle coast drag.
  - Steering moves `x` proportional to speed fraction. Centrifugal push `x -= curve * speed² * k` toward the outside. Tuned so a full-speed entry into curve ±5/±6 cannot be held with full steer (you go wide) but ≤ ~70% speed can.
  - Drift: full steer at > 75% speed for ≥ 6 ticks sets `drift`, adds 30% steering authority and bleeds speed ~1%/tick. Never spins.
  - Off-road `|x| > FX_ONE`: speed decays toward 35% of max. Wall at `|x| > FX_ONE*3/2`: clamp x, speed halves once per contact, `wall_hit` set for one tick (renderer flash).
  - Hills: uphill slope subtracts a little speed, downhill adds a little.
  - `z` never goes below 0 (clamp, speed set to 0 if reversing into it).

- [ ] **Step 1:** Write tests in `tests/test_physics.c` against a straight test track and a `curve=6` track built inline:
  - `test_deterministic`: two cars, same 900-tick pseudo-random input sequence (LCG seed 1) → identical `z,x,speed` every tick.
  - `test_accel_and_topspeed`: 600 ticks of gas on straight → speed within 2% of `MAX_SPEED`, never above it.
  - `test_brake_beats_coast`: from top speed, 30 ticks brake gives lower speed than 30 ticks coast; gas+brake same as brake.
  - `test_reverse`: brake held from standstill → speed goes negative, reaches `-MAX_REVERSE` and not beyond.
  - `test_no_reverse_past_start`: reversing from z=50 → z clamps at 0.
  - `test_too_fast_goes_wide`: enter curve=6 at `MAX_SPEED` holding full inside steer → `|x| > FX_ONE` within 90 ticks.
  - `test_braked_entry_holds_line`: enter at 65% speed, a simple controller (steer inward when `x` drifts outward past 0.3) keeps `|x| <= FX_ONE` for 150 ticks.
  - `test_wall_slows`: x set beyond wall at speed S → after one step speed ≤ S/2 + small, `|x| <= FX_ONE*3/2`.
- [ ] **Step 2:** Run `make -f host.mk test` → physics tests fail.
- [ ] **Step 3:** Implement `car_step`.

### Task 3: Race state, ghost log, timing

**Files:** Create `src/race.h`, `src/race.c`, `tests/test_race.c`

**Interfaces:**
- Consumes: `car_t`, `car_step`, `track_t`.
- Produces:
  ```c
  #define TICKS_PER_SEC 30
  #define MAX_TICKS (TICKS_PER_SEC * 60 * 5)          /* 5 min cap = 9000 ticks */
  typedef struct { uint16_t ticks; uint16_t splits[MAX_CP]; uint8_t n_cp; uint8_t inputs[MAX_TICKS / 2]; } record_t; /* ticks==0 => no record */
  typedef struct {
      car_t car, ghost; const track_t *track; const record_t *best;  /* best may have ticks==0 */
      record_t run; uint16_t tick; uint8_t next_cp; uint8_t finished; uint8_t capped;
      int16_t last_split_delta; uint8_t last_split_cp;  /* delta in ticks vs best, valid if last_split_cp != 0xFF */
  } race_t;
  void race_start(race_t *r, const track_t *t, const record_t *best);
  void race_tick(race_t *r, uint8_t input);   /* no-op once finished or capped */
  uint8_t record_input(const record_t *rec, uint16_t tick);  /* nibble unpack */
  int race_is_new_best(const race_t *r);      /* finished && !capped && (best->ticks==0 || run.ticks < best->ticks) */
  void format_time(char out[10], uint16_t ticks);           /* "M:SS.hh", hundredths = ticks*100/30 */
  void format_delta(char out[10], int16_t dticks);          /* "+0.47" / "-1.20" */
  ```
  Ghost: `race_tick` steps `ghost` with `record_input(best, tick)` while `tick < best->ticks`; after that the ghost stays put. Inputs packed two per byte, low nibble = even tick.

- [ ] **Step 1:** Tests in `tests/test_race.c`:
  - `test_pack_roundtrip`: record 1000 pseudo-random inputs via `race_tick`, `record_input` returns each one.
  - `test_ghost_replays_exactly`: run a race with input sequence S to finish on track 0; start a new race with that run as `best` and the same S → `ghost` equals `car` every tick.
  - `test_checkpoint_once`: drive past cp0, reverse back before it, drive forward again → `run.splits[0]` set once (first crossing) and `next_cp` goes 0→1 only.
  - `test_finish_sets_ticks`: finished → `run.ticks == tick` at the finish crossing; further `race_tick` calls change nothing.
  - `test_cap_run`: zero input for `MAX_TICKS + 10` ticks → `capped == 1`, `tick == MAX_TICKS`, `race_is_new_best == 0`.
  - `test_format`: `format_time(0)` = `"0:00.00"`, `format_time(30)` = `"0:01.00"`, `format_time(1835)` = `"1:01.16"`; `format_delta(14)` = `"+0.46"`, `format_delta(-36)` = `"-1.20"`.
  - `test_split_delta`: with a best whose `splits[0]=100`, crossing cp0 at tick 110 → `last_split_delta == 10`, `last_split_cp == 0`.

### Task 4: Save format and fileioc save

**Files:** Create `src/savefmt.h`, `src/savefmt.c`, `src/save.h`, `src/save.c`, `host/shim/fileioc.h`, `host/shim/shim.c` (fileioc part only), `tests/test_save.c`

**Interfaces:**
- `savefmt.h`:
  ```c
  #define SAVE_MAGIC 0x52   /* 'R' */
  #define SAVE_VERSION 1
  size_t save_serialize(const record_t *rec, uint8_t *buf, size_t cap);   /* returns bytes written, 0 if cap too small */
  int save_parse(record_t *rec, const uint8_t *buf, size_t len, uint8_t expect_n_cp); /* 1 ok, 0 invalid -> rec->ticks = 0 */
  ```
  Layout: magic, version, n_cp, ticks(u16 LE), splits[n_cp] (u16 LE), inputs[(ticks+1)/2], checksum (u8 sum of all prior bytes). Parse rejects: wrong magic/version, n_cp ≠ expected, ticks == 0 or > MAX_TICKS, len ≠ expected, splits not increasing or ≥ ticks, bad checksum.
- `save.h` (platform, fileioc): `void save_load(uint8_t track_idx, record_t *rec);` `int save_store(uint8_t track_idx, const record_t *rec);` AppVar names `RCRSV0`..`RCRSV5`; temp `RCRTMP`. `save_store`: write temp, archive it; on any failure delete temp and return 0 leaving the old one; on success delete old, rename temp → final.
- Host shim fileioc: AppVars are files in `$SHIM_DIR` (default `build/appvars/`); `shim_fail_archive` global makes `ti_SetArchiveStatus` fail.

- [ ] **Step 1:** Tests in `tests/test_save.c` (link with `save.c` + shim):

  - `test_save_keeps_old_on_failure`: store best A, set `shim_fail_archive = 1`, store B → returns 0, `save_load` still yields A.

### Task 5: Renderer + host graphics shim + sim screenshots

**Files:** Create `src/render.h`, `src/render.c`, `host/shim/graphx.h`, `host/shim/keypadc.h`, `host/shim/tice.h`, extend `host/shim/shim.c`, `host/sim.c` (temporary driver for this task), `host/ppm2png.py`, `tests/test_render.c`

**Interfaces:**
- Consumes: `race_t`, `track_t`, `format_time`, `format_delta`.
- Produces:
  ```c
  void render_init(void);                         /* palette */
  void render_race(const race_t *r, uint8_t show_fps, uint8_t fps);
  int  project_y(int32_t dz, int32_t dy);         /* screen y for a point dz ahead, dy above camera; exposed for test */
  ```
- Rendering approach (decided): classic segment projection. Camera 1000 units above road, behind car. Draw `DRAW_SEGS = 70` segments far-to-near is NOT used; draw near-to-far with a running `clip_y` and fill each segment's road/grass/rumble trapezoid as horizontal spans via `gfx_HorizLine_NoClip` (one span per scanline, x interpolated), skipping fully-hidden segments. Curves accumulate `dx += curve` per segment (Lou's method). 8-bit palette, double buffering (`gfx_SetDrawBuffer` / `gfx_SwapDraw`). Sky: two-tone bands, scrolled horizon hills shifted by accumulated curve. Rumble strips and lane stripes alternate every 3 segments for speed feel. Roadside posts every 8 segments, checkpoint gates as a colored bar across the road, finish as checkered bar.
- Car: drawn from filled rectangles/triangles at screen bottom, leaning with steer; ghost drawn at its projected z/x with the same shape in a dim palette color, only when ahead within draw distance (behind = not drawn).
- HUD: time top-left, best time below, speed (km/h-ish = speed>>8 * 3) bottom-right, split delta center for 2 s after a checkpoint (green negative, red positive), `wall_hit` = red flash border, optional fps top-right.
- Host shim graphx: 320×240 8-bit buffer + palette, implements only the gfx_* calls render/main use; text drawn as filled boxes the width of `8*len` (`shortcut: no font in shim, add one if text layout needs visual checking`). `shim_dump_ppm(path)`.
- Sim (this task): builds a race on each track, steps 90 ticks with gas, dumps `build/shots/track<N>.ppm`, `ppm2png.py` converts.
